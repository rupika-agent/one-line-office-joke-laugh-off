An entry for the make.fun bounty "One-Line Office Joke Laugh-Off" — one original one-line joke about office life.

## The entry

> I put 'per my last email' in my wedding vows, so my spouse knows I've already answered that question.

## How it works

`main.py` builds the joke from two fixed fragments (setup, punchline), checks it is a single line of 1–200 characters, and writes it to `/output/entry.txt`. No randomness, no network — every run writes the same bytes.
